  Termux 설치 (한 번에 복사)
═══════════════════════════════════════════════════

■ frontend/dist/index.html 없음 오류
  → zip **전체**를 풀지 않고 run.py만 복사한 경우
  → 또는 unzip 경로가 ~/aidi 가 아닌 경우

■ 아래 전체를 Termux에 붙여넣기:

pkg update -y
pkg install -y python python-pip python-venv python-numpy unzip
termux-setup-storage

cp ~/storage/downloads/aidi-samsung-tablet.zip ~/
cd ~
rm -rf ~/aidi
unzip -o ~/aidi-samsung-tablet.zip -d ~
cd ~/aidi
ls frontend/dist/index.html
python run.py

■ ls frontend/dist/index.html 이 "No such file" 이면
  ls ~
  ls ~/aidi
  → aidi 폴더가 없으면 zip 파일이 손상됐거나 예전 버전
  → GitHub에서 aidi-samsung-tablet.zip 다시 받기

■ Permission denied (.venv/lib64)
  → SD(/storage/emulated/0) 말고 위처럼 ~/aidi 만 사용

■ 브라우저: http://127.0.0.1:8000
