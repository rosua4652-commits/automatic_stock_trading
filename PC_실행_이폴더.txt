[PC에 최종본 맞추기 — 순서]
  ※ GitHub 커밋만으로는 PC 파일이 안 바뀝니다. 반드시 2번 실행!

  1. run.bat 이 돌아가 중이면 Ctrl+C 로 종료
  2. download-latest-pc.bat 더블클릭  ← PC 파일 실제 업데이트
     (없으면 PC_지금_업데이트.txt 의 CMD 방법 B)
  3. SETUP_PC.bat 또는 run.bat 실행
  4. check-build.bat → build: 2026-03-30-pc-dongil3-final
  5. probe-upbit.bat → 업비트 연동 확인
  6. 설정 → Access + Secret 저장 → 연결 테스트

  backend\data\credentials.json 은 덮어쓰지 마세요 (API 키).


[증상] 'l' / 'exist' 명령 오류
→ 잘못된 폴더이거나 예전 LF 배치 파일
→ GitHub 최신 받은 뒤 SETUP_PC.bat / run.ps1


[증상] check-upbit-ip 에서 {"error":"not found"}
→ 구버전 코드. sync-pc-from-github.bat 후 run.bat 재시작


[빌드 확인]
  - check-build.bat
  - http://127.0.0.1:8000/api/version
    → "build":"2026-03-30-pc-dongil3-final"
