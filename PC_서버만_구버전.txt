verify-pc-install 결과가 이렇게면
==================================

  [OK] Disk: latest build
  [FAIL] Server: OLD - returns error not found

→ 파일은 최신입니다. 예전 Python 서버만 아직 8000 포트에서 돌고 있습니다.


[해결 — 1분]

  1) stop-aidi.bat 더블클릭
     (또는 run.bat 검은 창에서 Ctrl+C)

  2) restart-aidi.bat 더블클릭
     (또는 run.bat 다시 실행)

  3) verify-pc-install.bat 다시 실행
     → [OK] Server: running latest build

  4) 브라우저 http://127.0.0.1:8000 새로고침 (Ctrl+F5)

  5) 설정 → 실거래 → 키 저장 → 연결 테스트


[여전히 FAIL 이면]
  - run.bat 을 (8) 폴더에서 실행했는지 확인
  - 다른 폴더 (6) 에서 run.bat 이 켜져 있지 않은지 확인
  - 작업 관리자에서 python.exe 여러 개 종료 후 1~2 다시
