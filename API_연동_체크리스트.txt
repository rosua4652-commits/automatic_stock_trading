API 연동이 안 될 때 (GitHub 받았어도)
====================================

[1] 먼저: 정말 최신 코드인가?
  verify-pc-install.bat 실행

  FAIL 이면 → GitHub ZIP이 이 폴더에 안 들어온 것
  또는 run.bat 을 안 끄고 예전 서버만 돌아가는 것

  check-build 에서 {"error":"not found"} = 100%% 구버전 서버
  → API 연동은 최신 빌드에서만 됩니다.


[2] 최신이면 — 업비트 설정 순서
  1. 설정 → 실거래 선택
  2. Access Key + Secret Key 둘 다 붙여넣기
  3. [저장] 클릭 (연결 테스트 전에 필수)
  4. [연결 테스트]
  5. 실패 시 메시지의 IP 를 업비트 Open API → 해당 키 → 허용 IP 에 등록
  6. probe-upbit.bat 으로 PC에서 재확인


[3] 자주 하는 실수
  - 모의투자 모드에서 API 칸이 안 보이거나 연동 안 됨
  - Secret 안 넣고 저장 (예전 키 + 새 Access 짝 불일치)
  - 업비트에 다른 키에만 IP 등록
  - VPN 켜서 IP 변경
  - 구버전 서버 그대로 실행 (파일만 바꿨는데 run.bat 안 재시작)


[4] 성공 기준
  verify-pc-install → [OK] Disk + Server
  연결 테스트 → 연결 성공 · 계정 N개
  상단 배너 → 구버전 경고 없음
